## 🚀 Sobre mí

Soy un **Desarrollador Full Stack** apasionado por la tecnología, la ciberseguridad y la arquitectura de software. Me dedico a construir soluciones robustas, eficientes y seguras, optimizando flujos de trabajo de desarrollo mediante el uso de Inteligencia Artificial. 

- 🔭 **Actualmente trabajando en:** Desarrollo de aplicaciones escalables y sistemas seguros.
- 🐧 **Mi Entorno de Trabajo:** Utilizo diariamente ecosistemas Linux, especializándome en **Arch Linux** para desarrollo puro y **Kali Linux** para entornos de seguridad.
- 💬 **Pregúntame sobre:** Arquitectura en Java, Spring Boot, ecosistema React y optimización de bases de datos.
