## Sobre mí

Soy un **Desarrollador Full Stack** apasionado por la tecnología, la ciberseguridad y la arquitectura de software. Me enfoco en construir soluciones robustas, eficientes y seguras, optimizando flujos de trabajo de desarrollo con Inteligencia Artificial.

- **Desarrollo Móvil:** Especial interés y pasión por el **desarrollo Android**, construyendo aplicaciones modernas, fluidas y de alto rendimiento.
- **Diseño Web & Frontend:** Gran afinidad por estéticas visuales de vanguardia como **neo-futurismo**, **glassmorphism** y **brutalismo** para la creación de interfaces web impactantes e interactivas.
- **Entorno de Trabajo:** Manejo diario de ecosistemas Linux, especializándome en **Arch Linux** para desarrollo puro y **Kali Linux** para análisis de seguridad y auditoría.
- **Backend & Arquitectura:** Desarrollo enfocado en Java con Spring Boot, Python con Django, TypeScript/JavaScript y modelado de bases de datos relacionales.
